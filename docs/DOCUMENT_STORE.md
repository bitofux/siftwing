# 偏移表与文档随机读取

当前提供 `siftwing_document_store`：从只读派生记录库生成拥有型偏移表、编码/解码该表，
以及持有文件句柄的随机读者。记录库沿用[记录格式 v1](RECORD_FORMAT.md)，本模块不改变
其字节布局。不实现 manifest、快照发布、词典/倒排、mmap、压缩或正式 CLI。

`OffsetTable` 是可修改值容器，不能由构造推导有效；消费前重新验证。条目按 DocId 严格
升序排列、身份唯一，0 与 UINT64_MAX 均合法，不要求连续。每项为 DocId、offset、length
三个 uint64；后两者从记录库起点按字节计，length 包含完整记录头/前缀/载荷且至少为 88。
按物理偏移排序后，区间必须从 0 无洞、无重叠地覆盖完整库；不允许隐藏尾随数据。
验证用 `length <= library_bytes-offset` 检查范围，再推进已证明安全的游标，不先加再查。

SWDI v1 偏移表使用网络字节序，不序列化 C++ 对象内存：

| offset | 字节数 | 含义 |
|---|---|---|
| 0 | 4 | ASCII `SWDI` |
| 4 | 2 | 独立表版本，必须为 1 |
| 6 | 2 | 头长，必须为 32 |
| 8 | 8 | 条目数 |
| 16 | 8 | 完整记录库字节数 |
| 24 | 4 | CRC-32/ISO-HDLC |
| 28 | 4 | 保留字段，必须为 0 |
| 32 | 每项 24 | 严格升序 DocId、offset、length，各 8 字节 |

完整表长度为 `32+count*24`。CRC 跳过 `[24,28)`，覆盖其余所有字节，与
`zlib.crc32(bytes[:24]+bytes[28:])` 一致；参数与记录 CRC 相同。未知头/版本/保留位、
计数溢出、长度不匹配、截断/尾随、CRC 不匹配、非法顺序或覆盖均拒绝。
CRC 不提供认证，不能抵抗同时改写表、库和校验码的写者。

调用方显式给出五项正预算：既有单字段/单记录字节，以及文档数、库总字节、表总字节。
表/记录的框架计入预算，等于上限合法；空库对应空表，表编码仍占 32 字节。
生成表逐条校验记录，不缓存全库；生成过程中也先检查下一表项的编码预算。
表校验/构建排序为 O(n log n)，记录 CRC 为 O(库字节数)；容器开销、复制峰值和进程
硬内存/CPU 限额不由这些预算保证。

`DocumentStoreReader::open(path,table,limits)` 先验证表，再以
`O_RDONLY|O_CLOEXEC|O_NOFOLLOW|O_NONBLOCK` 打开文件，fstat 只接纳普通文件并核对库大小。
只拒绝叶子符号链接，不保证父组件无链接；调用方负责可信的派生库路径，不用它读取原始
私有输入。打开时逐项读取并验证记录结构/CRC/DocId，使“等长但指向另一记录”也不能通过。
成功读者拥有独立表副本与只读 fd；不会保存外部表或输入字节的借用。

`read(DocId)` 二分查找，`pread` 不改变共享文件游标，短读继续、EINTR 重试、EOF/其他错误
返回失败。分配前检查范围、容量及 off_t；读前后核对文件大小，再验证完整记录和身份，
复制为拥有型 DocumentRecord，保留全部字段、原字节以及可选元数据缺失/空值的区别。
读者析构后返回文档仍有效。不验证 UTF-8、来源路径、URL 或日期语义，沿用记录层边界。

读者不可复制，允许 noexcept 移动/赋值；源成为 closed/空表，read 返回 `store.closed`。
移动赋值先关闭旧只读 fd，自移动保持。析构关闭一次，忽略只读 close 失败且不重试，
不承诺 errno 保持。`entries()` 只从左值借用只读引用，移动/赋值/析构使借用失效。
独立 const read 不共享 seek 状态，但文件必须稳定，不能与读者移动/析构并发。

这不是原子文件快照。文件大小变动会拒绝，但未读记录的同长变动、校验后的改写或重新
计算 CRC 不保证发现；未来 manifest 另行承担完整快照身份。单独扫描库无法知道原本应该
有多少文档，因此完整记录前缀可成为一份合法新库；使用原表打开时，库大小不符仍须拒绝。
路径被重命名或删除不会改变已经打开的 inode，读者在 fd 存活期间仍可读取原文件。

普通失败为拥有型 Result，无部分表/文档/读者；已打开的局部 fd 由 RAII 释放。
context 包括 `store.limits/path/file/io/length/closed/not_found/identity` 以及
`store.table.header/length/checksum/range/order`；记录损坏沿用 `record.*` 原诊断。
分配和未知异常上传，不伪装为格式失败。本模块不写输入，不创建/删除生产输出或发布文件。
