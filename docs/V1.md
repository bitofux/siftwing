# V1 单机离线检索基线

V1提供C++17/Linux离线建库与本地SEARCH/SUGGEST。正式应用为
[siftwing-indexer](INDEXER.md)和[siftwing-cli](CLI.md)，测试输入来自公开原创MIT夹具。
本页说明代码能力、验收方法与限制；工程验收和学习者掌握分别需要实际证据。

## 能力与依赖方向

```text
TXT / RSS XML（HTML正文抽取）
  → 规范化 / 英文或cppjieba分词 / 停用词 / 单文档TF
  ├─ 搜索输入 → SimHash去重 → 保留记录 / 倒排 / TF-IDF与L2权重
  └─ 推荐输入 → 全交付独立累计 → 推荐词典 / 字符索引
  → Writer发布完整八文件快照
  → Reader完整校验并拥有两支数据
  ├─ SEARCH → Query → AND/OR候选 → 余弦稳定top-k → 原DocId记录 → 摘要/高亮
  └─ SUGGEST → 共享字符召回 → Unicode标量编辑距离 → 稳定推荐
```

V1实现统一归档到`siftwing_v1`，完整服务通过`siftwing_full`复用；命令与纯V1入口见[构建指南](BUILDING.md)。查询核心不调用文件装载或Writer。输入装载、资源
选择和接线由应用负责。标题/URL等元数据保持原文本，文本分析只消费正文。
TXT一文件一篇；RSS经XML字段选择与必要HTML抽取进入同一文本管线。

搜索保留集中的DocId可能有空洞，不是记录数组下标。搜索N/DF在去重后统计；推荐按
自己所选语料全部交付累计，推荐次数不是DF，两支资源及词ID独立。SUGGEST后由调用方
选择词再SEARCH；推荐词不在搜索库时可合法无匹配，CLI不自动替换查询。

## 从公开输入运行

以下命令使用英文分词和公开原创TXT/RSS输入；先按[README](../README.md)构建Release。
输出父目录须已存在，每次选未发布的版本。`mktemp`创建隔离目录，程序不覆盖已有版本。

```sh
v1_output=$(mktemp -d /tmp/siftwing-v1.XXXXXXXX)
build/release/siftwing-indexer \
  --output "$v1_output" --version 1 --build-version local-v1 \
  --search-txt tests/fixtures/golden/txt/en-river.txt \
  --search-rss tests/fixtures/golden/rss/original.xml \
  --recommendation-txt tests/fixtures/golden/txt/en-workbench.txt \
  --recommendation-rss tests/fixtures/golden/rss/original.xml
build/release/siftwing-cli SEARCH --snapshot "$v1_output" --version 1 \
  --query 'lantern' --mode or --top-k 5
build/release/siftwing-cli SUGGEST --snapshot "$v1_output" --version 1 \
  --key 'lantern' --top-k 5
```

`local-v1`仅为演示标签，不能当作源码验证身份。正式证据须记录实际提交、必要未提交
差异/哈希、依赖和环境。中文用法和预算选项见[INDEXER](INDEXER.md)/[CLI](CLI.md)。

## 完整验证

Debug和Release分别按README配置/构建/运行全量CTest。ASan与UBSan使用独立Debug目录：

```sh
cmake -S . -B build/asan-ubsan -DCMAKE_BUILD_TYPE=Debug \
  -DSIFTWING_ENABLE_SANITIZERS=ON
cmake --build build/asan-ubsan --parallel
ctest --test-dir build/asan-ubsan --output-on-failure --no-tests=error

cmake -S . -B build/production -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF
cmake --build build/production --parallel
```

生产配置按定义不注册测试；验证应针对测试配置要求非空CTest，再针对生产配置确认实际
应用构建与运行。公开测试不依赖私有原始语料、课程答案或上游默认中文词典。

## 所有权、失败与证据限制

应用拥有装载字节/资源；文本分析返回拥有结果。Writer同步借用已验证部件，RAII释放
句柄，原子无覆盖发布。失败可能保留临时目录；提交后父目录同步失败的`sync_uncertain`
不能解释为没有发布。Reader完整校验后返回拥有部件，调用结束无长期fd；const getter
返回借用，移动/赋值/析构后失效。CLI持有Reader直到查询、显示与JSON完成。

非法参数、输入/业务失败、输出失败、异常按应用退出码区分。完整校验前不交付部分
Reader或成功报告；stdout实际写出失败可能留下前缀。所有预算都是有限工作/尺寸准入，
不包含全部容器/分配器/第三方临时成本，不是进程硬内存上限或真实OOM安全证明。

输入、资源和快照在调用期间须稳定，路径检查不承诺敌对并发写者的原子一致性。
manifest/config摘要不是真实性认证，也不能自动恢复或认证资源相容。保存权重要求既有
IEEE754/FE_TONEAREST/严格浮点环境；跨CPU/libm逐位复现不作保证。

V1不包含TCP/Reactor、线程池、缓存、HTTP/UI或在线热切换。当前验证不证明大规模性能、
真实OOM、任意并发、TSan、跨平台、私有业务质量或断电恢复。fd观察不能单独证明heap
无泄漏；sanitizer仅覆盖运行到的路径。公开小语料闭环与历史私有TXT接入验收具有不同
范围，不能互相替代或据此宣称私有RSS/全部语料质量已验证。

阶段工程门禁须结合所有必做能力、全量验证、Review和交接；学习门禁另要求学习者亲自
完成“文档到快照”“查询到结果”的调试、故障实验及代表性修改。自动测试和本文不证明
学习者已经掌握V1。

亲自回放的命令、观察问题、可控故障和隔离 C++ 修改任务见[V1调试学习包](V1_DEBUGGING.md)。
该入口提供学习材料；完成材料准备不表示本人已经通过学习门禁。
